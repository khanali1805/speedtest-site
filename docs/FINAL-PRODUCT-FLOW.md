# SmartCalc Final Product Flow

## Bills
Current bill image + current meter image are the primary inputs.
Previous bill + previous meter are optional comparison inputs.
Mobile users get camera capture and gallery selection. Desktop users get the file picker.
OCR values remain editable before final use.

## Wi-Fi
Start a timed 8-second Internet baseline. It stops automatically.
Then walk through the home while the interface records connection samples.
The home view is a top-view model. The locator is head-only and points in the device direction when the browser provides orientation.
Strong/Fair/Weak areas use animated radio-wave markers.
Live geolocation is excluded.

## Accuracy
Internet throughput and latency are measurements. Room layout and router distance are modelled visualization values.
